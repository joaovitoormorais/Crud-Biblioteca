## Crud-Biblioteca

## 📚 Sistema de Biblioteca -  Spring Boot API

Sistema de gerenciamento de biblioteca desenvolvido com Spring Boot.  
Este projeto tem como objetivo oferecer uma **API RESTful para operações CRUD** de livros, autores e categorias, permitindo **cadastrar, listar, buscar, editar e excluir** informações relacionadas à biblioteca.

---

## 📌 Funcionalidades

✅ Cadastrar novo livro  
✅ Listar todos os livros  
✅ Buscar livro por ID  
✅ Buscar livros por título, autor ou categoria  
✅ Atualizar dados de um livro  
✅ Excluir livro  
✅ Cadastro e gerenciamento de autores e categorias  
✅ Validações com Bean Validation  
✅ Mapeamento com DTOs
✅Tratamento de exceções personalizado com mensagens amigáveis

---

## 💻 Tecnologias Utilizadas

- Java 21  
- Spring Boot  
- Spring Web  
- Spring Data JPA  
- Bean Validation
- Lombok  
- Banco de Dados H2 (para testes)  
- Banco de Dados PostgreSQL (produção ou desenvolvimento)
